# 🚀 Portofolio Pribadi — Tema Luar Angkasa

Website portofolio interaktif yang dibangun untuk memenuhi tugas **Proyek Website Portofolio Pribadi (Mapel Pilihan TKJ)**.

## 🛠️ Teknologi yang Digunakan
- **HTML5 Semantik** (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **Tailwind CSS (CDN)** & **Custom CSS3**
- **JavaScript (Vanilla JS)** untuk manipulasi DOM, filter proyek, modal detail, validasi form, dan animasi latar bintang.

## ✨ Fitur Utama
1. Desain responsif (*mobile-first*) dengan navigasi hamburger menu.
2. Filter kategori proyek dinamis (Semua, Web App, Game, UI/UX).
3. Modal pop-up untuk melihat detail teknis setiap proyek.
4. Validasi form kontak secara *real-time*.
